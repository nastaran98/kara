## Direction contract

THESIS: Kara is a working slip-box, not a dashboard — today's practice is one sourced index card pulled from the box and filed. This refuses the card-grid/stat-tile wellness-SaaS arrangement every app in this category ships (and that Kara itself currently ships).

OWN-WORLD: Kraft-cream ground (#F6F1E4), graphite ink text (#2B2A26), a faded stamp-blue for structure (#4A5A8C, replacing the flat UI-indigo accent), brass for accomplishment (#B8863B, replacing the amber accent). Typewriter/mono type for citations, dates, and metadata; a warm humanist face for practice body text. Colored guide tabs — reusing the existing ACT/SIT/NOTICE/KEEP hues — mark practice type at a card's edge, not as flat icon-chip fills. One type size per card; rank comes from weight, case, and rule only, never a second size. Card states (fresh / pulled / filed / overdue) render as a fixed tonal-density ladder, never ad hoc opacity.

STORY: The visitor understands they are handling one specific, attributed idea, not browsing a feature list. They pull today's card, act on it, and file it. Filing stamps today's date onto the card's own ledger — that stamped record IS the streak, not a badge or progress ring.

FIRST VIEWPORT (Today): a single oversized index card fills the viewport edge-to-edge. A colored guide tab at its left edge names the practice type. The source citation is typed along the card's bottom rule. The "file" (complete) action sits where the tab meets the rule — the primary action, not a floating button.

FORM: Zettelkasten / index-card slip-box. Index 3 of 7 on the grounded, resonance-ordered list (sheet-music practice log, e-reader highlight/margin interface, **slip-box [assigned]**, page-a-day almanac, knitting row-counter, library due-date card, field-guide specimen log). Seed key 2010d92b.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
